# Security reports

Do not publish credentials, private device logs or exploitable details in public
issues. Use GitHub private vulnerability reporting when enabled on this repository.
If unavailable, open an issue requesting a private reporting channel without the
sensitive details. Never attach tokens, firmware contents or unredacted logs.

PortWave is a device-debugging utility. Review the port/host and send content before
connecting or transmitting. Hardware behavior is outside simulated test coverage.
