# 0017 日志刷新仅追加尾部

2026-11-07。

用户要求日志读取窗口刷新时只增加新日志，不重读或重建已有日志。首次打开仍使用后台完整快照和独立 Scintilla ILoader；刷新改为沿每个 Document 的检查点继续读取源文件。

FileService 的 FileReadCursor 是可复制值，记录源字节偏移（包括 ANSI/BOM）、文件身份、最多 64 字节边界校验、UTF-8 校验和换行/BOM 状态。Windows 使用卷与文件索引识别同路径替换。每次尾部读取最多 256 KiB，128 KiB 分块；剩余积压通过下一次异步任务续读，不逐行发 GUI 信号。只有源偏移前的最后 64 字节用于连续性校验，不重读/解码历史正文；更早位置被原地修改不会更新已显示的旧内容。这是追加阅读器，不是任意文件修改同步器。

LogDocumentView 将每次读取的 ANSI 解码器及 UTF-16 位置复制到后台独立状态，保留跨写入的颜色、半条 ANSI 和半个 UTF-8 字符。首次打开实时日志也允许不完整尾字符，待后续补齐；FileService 其它默认调用仍严格拒绝不完整 UTF-8。成功追加后才提交读取/解码检查点，取消和错误均丢弃未提交批次。复制工作区复制读取检查点，后续独立推进。关闭标签时丢弃在途尾部结果。

EditorInterface::appendLogUtf8 仅 GUI 线程使用，追加到原文档并恢复选区方向和滚动。只初始化新范围颜色/指示器并延续样式游标与颜色编号，不扫描/重画旧样式或重新应用旧标记；显式主题/颜色切换仍可按原语义重绘视图。样式缓存独立持有，增长预留容量避免每批复制全部旧样式。

检测到文件缩短、身份变化或边界字节改变时不自动清空/重载旧日志：保留当前页面、停止该页自动刷新并提示关闭标签后重新打开。这样不会把分卷后的另一个文件拼到当前记录。文件读取/追加错误保留旧正文与检查点，修复后可以重试。
