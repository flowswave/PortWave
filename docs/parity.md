# 功能状态与限制

| 范围 | 当前实现 | 验证边界 |
|---|---|---|
| 串口 / TCP | 多连接、基础串口配置、文本/HEX/混合收发 | 模拟连接和 TCP 回环；不同物理设备需实测 |
| 终端 | UTF-8、ANSI 彩色、暂停、显示行数上限、有界数据队列 | 不实现完整 xterm 光标控制和终端仿真 |
| 发送 | CR/LF、草稿、快捷命令、发送历史、定时发送 | 长期时序和真实设备响应需实测 |
| 存盘 | 时间标签、分卷、默认纯文本、可保留控制码 | 流式过滤和模拟写盘已测，慢盘/满盘需实测 |
| 日志阅读 | 多工作区/标签/浮窗、后台初次加载、尾部增量刷新 | UTF-8；非磁盘分页，容量受内存限制 |
| 查找与标记 | 普通/扩展/正则、历史结果、定位、八组文字标记 | 搜索结果有数量上限；部分操作仍需要完整内存快照 |
| 外观 | 炫彩/明亮、按主题保存字体与控件风格 | 默认炫彩、紧凑、12 pt；真实多显示器矩阵需实测 |
| 升级协议 | 协议/CRC/模拟成功路径 | 物理板卡及失败矩阵尚未全面验收 |
| 分发 | MSVC x64 绿色 ZIP / NSIS 安装包 | 打包启动检查不等同管理员安装/卸载验收 |

## 测试集合

`scripts/test.ps1 -Suite release` 运行核心、当前行为的 Qt 专项和应用启动检查。
GitHub Actions 运行跨平台纯核心构建/测试，不替代 Windows GUI 或硬件测试。

`-Suite all` 保留历史完整 Qt 集，其中仍有旧三主题/暂停按钮预期和共享状态栏
用例问题。没有通过删测试来隐藏这些差异，发布子集通过不表述为全量通过。

发行候选的实际本地验证见 [validation.md](validation.md)。
