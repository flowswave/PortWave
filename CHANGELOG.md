# Changelog

## 0.1.0 — initial public release

- Windows C++20 / Qt 6 serial and TCP terminal with independent connections.
- Chromatic/light themes, compact defaults, staged settings and shared sending UI.
- Plain-text log saving, rotation, independent log workspaces and tail-only refresh.
- Search/result groups, ANSI-aware viewing, text marks and background cancellation.
- Separate portable ZIP and installer builds using an external MSVC toolchain.
- GPL-3.0-only publication with original dependency sources/notices and core CI.

This release starts a clean public history. Feature limits and test scope are
documented in `docs/parity.md`; it does not claim complete hardware acceptance.
