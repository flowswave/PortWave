# UI resource provenance

The shared widget QSS, initial semantic colors, small control SVGs and toolbar
icon paths originated from the earlier PortWave Python implementation. The
maintainer confirmed ownership or permission to publish these resources in this
GPL-3.0-only release. Subsequent Qt theme and contrast work is maintained here.

The application icon is the maintainer-provided blue terminal/P/wave image.
PortWave.origin.png records the supplied image; PortWave.png and the multi-size
PortWave.ico are its transparent/cropped application variants. The same ICO is
embedded in the Windows executable and loaded by the main/log windows.

The application builds entirely from this repository and its documented SDKs.
No earlier private project, reference Python environment or personal directory
is required. Third-party library notices remain separate and unchanged.
